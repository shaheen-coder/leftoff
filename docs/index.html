leftoff
shaheen-coder / leftoff

Never lose track of where you left off.

A fast, keyboard-driven CLI and TUI for tracking project features and issues, right from your terminal.

$pip install leftoff
View on GitHub PyPI package

Features

🗂️

Two lists, one tool

Track features and issues separately, in the same project file.

🆔

Structured tasks

Every task carries an id, description, due date, and status.

🖥️

A full TUI

Built with Textual, for browsing and managing tasks visually.

⌨️

A lightweight CLI

Add and update tasks without leaving the terminal.

🎨

Rich output

Formatted CLI output via Rich, readable at a glance.

⚡

Local-first

Pure Python. No services, no database, no config to manage.

Installation

Pick whichever fits your workflow.

$uv pip install leftoff
$pip install leftoff
$git clone https://github.com/shaheen-coder/leftoff.git
$cd leftoff
$uv sync

Quickstart

1

Initialize leftoff in your project

$leftoff --init
2

Add a feature task, due in 3 days

$leftoff --mode 'feat' --add "add other tasks,3"
3

Add an issue task

$leftoff --mode 'issue' --add "Fix crash on startup,1"
4

Update a task's status — id,status

$leftoff --mod "3,FIXING"
5

Remove a task by id

$leftoff --rm "3"
6

Launch the interactive TUI

$leftoff --tui

CLI reference

FlagDescription
--initInitialize a leftoff project (creates initial project details)
--mode 'feat'|'issue'Select which list to operate on: features or issues
--add "task,days"Add a new task; due date is days from today
--mod "id,status"Update a task's status — TODO, FIXING, or FIXED
--rm "id"Remove a task by its id
--tuiLaunch the interactive TUI

Run leftoff --help for the full, up-to-date option list.

How data is stored

Everything lives in a single leftoff.json file at your project root. No database, nothing to sync.

{
  "title": "my-project",
  "version": 0.1,
  "mode": {
    "feat": [
      { "id": 1, "task": "add mult file reading", "status": "TODO", "due": "12-08-2026" }
    ],
    "issue": [
      { "id": 1, "task": "fix the padding on encode function", "status": "FIXING", "due": "21-08-2026" }
    ]
  }
}

Every task moves through the same three statuses:

  • TODO
  • FIXING
  • FIXED
